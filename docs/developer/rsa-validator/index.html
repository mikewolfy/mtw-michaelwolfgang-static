RSA signature validator

Verify RSA-signed strings using a public key. Verification runs locally with the Web Crypto API — your data and keys never leave your device.

About RSA signature verification

RSA signature verification is a cryptographic process that confirms the authenticity and integrity of a message using asymmetric cryptography.

How it works

  • Signing: The sender uses their private key to create a digital signature of the data
  • Verification: Anyone can use the sender’s public key to verify the signature
  • Algorithm: Uses RSASSA-PKCS1-v1_5 with various hash functions (SHA-256, SHA-384, SHA-512)

Input requirements

  • Original data: The exact message that was signed (must match exactly)
  • Signature: Base64 encoded signature string
  • Public key: PEM format public key

Common use cases

  • Verifying API responses and webhooks
  • Authenticating software updates and downloads
  • Validating document signatures
  • Ensuring message integrity in secure communications

Tip: The original data must match exactly (including whitespace, line breaks, etc.) for the signature verification to succeed.
